# Data, fonts and model attribution

The source Persian-OCR-Dataset is by **Mojtaba Gandomkar and Sahar Khoramipour**, copyright 2025, distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Source: [dataset repository](https://github.com/SaharKhoramipour/Persian-OCR-Dataset); associated research: [Towards Omni-Font Optical Character Recognition (OCR) for Persian Script Using the YOLO Object Detection Model](https://doi.org/10.57647/j.mjee.2025.17063). Original archives and the supplied license are retained in `data/raw/persian-source/`. The audit interprets their class-name files into the project's 32-class Unicode map, documenting excluded classes and map discrepancies. No connected-text crops from these archives are included in this run's training or evaluation: contextual forms and complete dots have not been individually verified.

This run uses separately generated isolated-letter images from eight font families: Lateef, Markazi Text, Vazirmatn, Gulzar, Noto Naskh Arabic, Noto Sans Arabic, Amiri and Scheherazade New. Font files and copyright/license notices are downloaded from the [Google Fonts repository](https://github.com/google/fonts), retained per family under `data/raw/fonts/`, and covered by the supplied SIL Open Font License. Read each family's `OFL.txt` for its authors and reserved font names. Fonts remain unmodified; rendering, positioning and background generation create the project images. Font revision, source URL, file hash and original license are retained in `data/raw/provenance.json`. Do not substitute unlicensed fonts.

YOLO11n is initialized from [Ultralytics' v8.3.0 assets release](https://github.com/ultralytics/assets/releases/tag/v8.3.0) (`yolo11n.pt`). The installed Ultralytics package and pretrained assets have their own upstream licensing; their terms are separate from dataset and font licenses. Preserve those terms when redistributing models or application code. Initialization URL and hash are in `artifacts/pretrained/provenance.json`; fine-tuned weights have project metadata.

The reduced CNN follows the project position paper's adaptation of feature learning from [Safarzadeh and Jafarzadeh (2020)](https://doi.org/10.1109/CSICC49403.2020.9050073). Three convolution blocks, global average pooling, 64-pixel inputs and 32 logits are project choices. BLSTM and CTC are omitted. Published performance figures are not project results.
